# Face ID + Blockchain Verification

**HH GOA Hackathon — Task #3**  
A pipeline that detects a face, finds a matching social-media post via genuine reverse-image search, and writes the result to a blockchain as a tamper-evident record.

## How It Works

```
Input Image → Face Detect+Encode → Reverse Image Search → Blockchain Record → Verify
```

1. **Face Detection + Encoding** — OpenCV 5.0 `FaceDetectorYN` (YuNet) detects the face, `FaceRecognizerSF` (SFace) produces a 128-d embedding. Both run fully offline via ONNX models.
2. **Reverse Image Search** — SerpAPI's Google Lens engine finds where the image appears online. Results are filtered for social-media domains (Instagram, X/Twitter, Reddit, etc.).
3. **Blockchain Record** — The image hash, embedding hash, match URL, and timestamp are written to a `FaceMatchRegistry` smart contract on **Polygon Amoy testnet**.
4. **Verification** — The record is read back from the chain and compared against locally recomputed hashes to prove tamper-evidence.

## Blockchain

**Network:** Polygon Amoy testnet (EVM-compatible, free, fast)  
**Explorer:** [amoy.polygonscan.com](https://amoy.polygonscan.com)  
**RPC:** `polygon-amoy-bor-rpc.publicnode.com` (public, no key needed)  
**Contract:** `FaceMatchRegistry` — stores structured records and emits `MatchRecorded` events.

## Setup

### 1. Prerequisites

- Python 3.14+ with pip
- A **SerpAPI key** (free tier: ~100 searches/month) — [sign up](https://serpapi.com)
- A **throwaway testnet wallet** funded with Amoy MATIC

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure environment

```bash
cp .env.example .env
```

Edit `.env` and fill in:
- `SERPAPI_KEY` — your SerpAPI key
- `PRIVATE_KEY` — generated by `python scripts/new_wallet.py`
- `CONTRACT_ADDRESS` — auto-filled by `python scripts/deploy_contract.py`

### 4. Generate a testnet wallet

```bash
python scripts/new_wallet.py
```

Fund the printed address from the [Polygon Amoy faucet](https://faucet.polygon.technology).

### 5. Deploy the smart contract

```bash
python scripts/deploy_contract.py
```

This compiles `FaceMatchRegistry.sol`, deploys to Amoy, and saves the contract address to `.env`.

## Run

```bash
# From a local image file
python main.py --image samples/your_photo.jpg

# From a public URL
python main.py --image-url https://example.com/photo.jpg
```

Output:
- Console logs showing each pipeline stage
- `output/face_crop.png` — aligned face crop
- `output/result.json` — full pipeline result (hashes, search match, tx link, verification)

## Known Limitations

- **Image matching, not person matching** — The reverse-image search matches the exact image, not the same person across different photos. If the input photo isn't published online, no social match is found.
- **SerpAPI free tier** — ~100 searches/month. Local images are uploaded to temporary hosts (catbox.moe, 0x0.st, tmpfiles.org) which may rate-limit. Use `--image-url` to bypass.
- **RPC availability** — The default Polygon public RPC (`rpc-amoy.polygon.technology`) can be unreliable. The project uses `polygon-amoy-bor-rpc.publicnode.com` as a fallback.
- **Testnet only** — Polygon Amoy test tokens have no real value. This is a proof-of-concept, not production infrastructure.
- **Demo-grade recognition** — SFace is a lightweight recognizer; it is not production biometric security.
- **Single face** — Picks the highest-confidence face; minimal multi-face handling.

## Ethics

**Only process images you are authorized to use.** This tool is a hackathon demonstration. Misuse for surveillance, stalking, or unauthorized identification is unethical and may be illegal.
